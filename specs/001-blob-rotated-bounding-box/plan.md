# Implementation Plan: Rotated Rectangle Bounding Box for Semantic Blobs

**Branch**: `001-blob-rotated-bounding-box` | **Date**: 2026-10-01 | **Spec**: [spec.md](spec.md)

**Input**: Feature specification from `/specs/001-blob-rotated-bounding-box/spec.md`

## Summary

The objective of this feature is to calculate rotated rectangle bounding boxes that strictly enclose connected components (blobs) in a binary semantic segmentation mask (`.png`), maximizing the Intersection-over-Union (IoU) metric. The technical approach leverages `opencv-python-headless` for high-performance 8-way connected component segmentation and rotating calipers (`cv2.minAreaRect`) on the convex hull of each blob to compute the minimum-area enclosing bounding box (which mathematically maximizes enclosing IoU = `blob_area / box_area`). Results are exported to a timestamped CSV named `blob_bounding_boxes_{timestamp}.csv` containing the exact schema: `blob_id`, `center_x`, `center_y`, `width`, `height`, and `angle` (in `[-90.0, 90.0]` degrees rotated around the box center). The feature is delivered as a modular Python package under `src/blob_bounding_box/` accompanied by an interactive Jupyter notebook under `notebooks/` for end-to-end visualization.

## Technical Context

**Language/Version**: Python 3.12 on Linux (Ubuntu), managed via `uv`.

**Primary Dependencies**:
- `opencv-python-headless==4.11.0.86` (image reading, connected component labeling, rotating calipers)
- `numpy==2.2.3` (2D mask array manipulation)
- `loguru==0.7.3` (workflow observability and structured execution trace)
- `matplotlib==3.10.1` (visualization overlay in Jupyter notebook)
- `ipykernel==6.29.5` (Jupyter notebook execution kernel)
- `ruff==0.9.9` (formatting and linting gate)

**Storage**: Local filesystem; reads input `.png` masks (e.g., `data/example_mask.png`) and writes timestamped CSV files (`blob_bounding_boxes_{timestamp}.csv`).

**Testing**: Exclusively authored by human developers per Project Constitution Principle III. All modules are designed with pure functions, explicit inputs/outputs, and clean interfaces to facilitate straightforward human-authored unit and integration testing.

**Target Platform**: Linux (Ubuntu x86_64).

**Project Type**: Python library (`src/blob_bounding_box/`) + interactive Jupyter notebook (`notebooks/blob_bounding_box_experiment.ipynb`).

**Performance Goals**: Process a 1024x1024 binary mask with up to 50 blobs in under 10 seconds on standard hardware.

**Constraints**:
- Strict enclosing guarantee (100% blob pixel recall).
- All dependencies strictly pinned in `pyproject.toml`.
- All code formatted and imports sorted via `ruff`.
- Complete execution trace logged using `loguru`.
- Output CSV schema strictly restricted to: `blob_id`, `center_x`, `center_y`, `width`, `height`, `angle`.

**Scale/Scope**: Processing individual and batch 2D semantic masks ranging from low resolution to multi-megapixel masks.
